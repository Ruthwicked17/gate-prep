Transmission Lines, Cables, Per-unit

A transmission line is modelled by four distributed parameters per unit length: series resistance $R$, series inductance $L$, shunt capacitance $C$ and shunt conductance $G$ (usually neglected). How we lump them depends on line length. Per-unit quantities make multi-voltage systems easy to solve, and compensation adjusts reactive power to control voltage and power transfer.

KEY IDEAS
- Short line (below about 80 km): only series impedance $Z$; $A = D = 1$, $B = Z$, $C = 0$.
- Medium line (80 to 250 km): nominal-$\pi$ or nominal-T model. Long line: exact distributed model with hyperbolic functions.
- For any passive reciprocal line, $AD - BC = 1$; for a symmetric line, $A = D$.
- Ferranti effect: on a lightly loaded or open-circuited long line, receiving end voltage exceeds sending end voltage because charging current flows through the series inductance.
- Surge impedance loading (SIL): load at which reactive power generated by line capacitance equals that absorbed by line inductance; voltage profile is flat.
- Cables: much higher capacitance and lower inductance than overhead lines. Single-core cable insulation stress is highest at the conductor surface; grading (capacitance or intersheath) evens it out.
- Insulator strings: the disc nearest the line conductor carries the largest voltage because of shunt capacitance to the tower. String efficiency is below 100 percent; a guard ring improves it.
- Distribution: radial, ring main and interconnected systems; feeders carry constant current along length, distributors are tapped along their length.
- Per-unit: actual value divided by base value. Choose base MVA (common everywhere) and base kV (changes by transformer ratio). Transformer per-unit impedance is the same on both sides.
- Series compensation (capacitor in series) reduces net line reactance and raises power transfer capability. Shunt reactors absorb reactive power at light load; shunt capacitors supply it at heavy load.

FORMULAS
- Two-port: $V_S = A V_R + B I_R$, $I_S = C V_R + D I_R$
- Nominal-$\pi$: $A = D = 1 + \frac{YZ}{2}$, $B = Z$, $C = Y\left(1 + \frac{YZ}{4}\right)$
- Long line: $A = \cosh\gamma l$, $B = Z_c \sinh\gamma l$, $C = \frac{\sinh\gamma l}{Z_c}$, with $\gamma = \sqrt{zy}$, $Z_c = \sqrt{z/y}$
- Lossless: $Z_c = \sqrt{L/C}$, $\text{SIL} = \frac{V^2}{Z_c}$ (line-to-line kV gives MW)
- Voltage regulation: $\frac{|V_{R,NL}| - |V_{R,FL}|}{|V_{R,FL}|}$, with $|V_{R,NL}| = |V_S|/|A|$
- Power transfer (lossless): $P = \frac{|V_S||V_R|}{X}\sin\delta$
- Cable capacitance per metre: $C = \frac{2\pi\varepsilon_0\varepsilon_r}{\ln(R/r)}$ F/m; maximum stress $g_{max} = \frac{V}{r\ln(R/r)}$, minimised when $R/r = e$
- Base impedance: $Z_{base} = \frac{(\text{kV}_{base})^2}{\text{MVA}_{base}}$
- Change of base: $Z_{new} = Z_{old}\frac{\text{MVA}_{new}}{\text{MVA}_{old}}\left(\frac{\text{kV}_{old}}{\text{kV}_{new}}\right)^2$
- String efficiency: $\frac{V_{string}}{n \times V_{disc\,nearest\,line}}$

WORKED EXAMPLE
A generator rated 100 MVA, 11 kV has $X = 0.2$ pu. Express it on a 50 MVA, 10 kV base and find the ohmic value.
- $X_{new} = 0.2 \times \frac{50}{100} \times \left(\frac{11}{10}\right)^2 = 0.2 \times 0.5 \times 1.21 = 0.121$ pu
- $Z_{base,new} = \frac{10^2}{50} = 2\ \Omega$, so $X = 0.121 \times 2 = 0.242\ \Omega$
- Check on old base: $Z_{base,old} = \frac{11^2}{100} = 1.21\ \Omega$, and $0.2 \times 1.21 = 0.242\ \Omega$. Both routes agree.

COMMON TRAPS
- Using phase voltage in $Z_{base}$ with three-phase MVA; use line kV with three-phase MVA.
- Forgetting the $(kV)^2$ ratio when only the voltage base changes.
- Taking no-load receiving voltage equal to $V_S$; it is $V_S/A$, which is larger for long lines.
- In series compensation, degree of compensation is $X_C/X_L$; net reactance is $X_L - X_C$, not $X_L + X_C$.
- Insulator disc nearest the cross-arm carries the least voltage, not the most.
